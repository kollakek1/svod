# СВОД — стоматология сохранения

Лендинг частной стоматологии в Хамовниках: позиционирование «сохраняем свои зубы», прозрачные цены,
онлайн-запись на 4 шага и админка, в которой сотрудник живёт без инструкции.

> Демонстрационный проект. Бренд, врачи, отзывы, адреса и фотографии придуманы.
> Фото сгенерированы для макета, а не сняты в клинике — см. `public/images/CREDITS.md`.
> Перед публикацией: заменить контент, проверить политику конфиденциальности у юриста,
> задать реальные контакты и домен.

## Что внутри

- Один длинный лендинг: hero, манифест, приём, услуги с ценами, программы, врачи, клиника,
  клинические случаи, отзывы, FAQ, запись, футер.
- Онлайн-запись: услуга → врач → дата и время → контакты; слоты считает сервер, запись атомарна,
  экран успеха с кодом брони.
- Админка `/admin`: вход по email и паролю, календарь месяца и дня, статусы записей и история,
  редактирование услуг и врачей. Удаление услуг с будущими бронями блокируется.
- Служебные страницы: `/privacy`, 404, 500 (`error` и `global-error`).
- SEO: иконки, manifest, OG-картинка 1200×630 с кириллицей, `robots.txt`, `sitemap.xml`, JSON-LD
  (`Dentist`, услуги с ценами, FAQ).

## Стек

Next.js 16 (App Router, Turbopack) · React 19 · TypeScript strict · Tailwind CSS v4 ·
Radix UI (shadcn-подход) · zod · Postgres/Neon или файловое хранилище · vitest.

Шрифты: Spectral (дисплей), Golos Text (текст), JetBrains Mono (метки). Все с кириллицей.

## Запуск

```bash
npm install
cp .env.example .env.local   # заполнить значения
npm run dev
```

Основные команды:

```bash
npm run typecheck   # tsc --noEmit
npm run lint
npm test
npm run build
```

## Переменные окружения

| Переменная | Зачем |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | canonical, OG, sitemap |
| `ADMIN_EMAIL` | почта владельца для первого входа |
| `ADMIN_PASSWORD` | пароль владельца; хешируется при первом входе |
| `ADMIN_SESSION_SECRET` | подпись сессионной cookie |
| `DATABASE_URL` | Postgres; без него — `.data/*.json` |

Секреты не коммитятся. `.env.local` в `.gitignore`.

## Данные

Без `DATABASE_URL` данные пишутся в `.data/*.json` и переживают перезапуск.
На проде нужен Postgres: файловая система в serverless не сохраняется между вызовами.
Каталог при первом обращении создаётся из `src/content/clinic.ts`.

Демонстрационные записи для календаря:

```bash
node scripts/seed-demo-bookings.mjs
```

Скрипт перезаписывает `.data/bookings.json` восемью записями на неделю 23–27 ноября 2026.
Запускать только локально: на проде данные не должны затираться.

Подготовка изображений (исходные PNG → webp с нужными пропорциями):

```bash
node scripts/prepare-images.mjs
```

Смоук-тест API на живом сервере (каталог → слоты → бронь → админка → каталог):

```bash
BASE_URL=http://localhost:3000 ADMIN_EMAIL=… ADMIN_PASSWORD=… node scripts/smoke.mjs
```
