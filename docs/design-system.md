# СВОД — дизайн-система и арт-дирекшн

Источник истины по бренду — `docs/brief.md`. Токены уже лежат в `src/app/globals.css`;
этот документ объясняет, как их применять и как выглядят секции.

**Три запрета, которые дороже всего стоят:**
1. Второй акцентный цвет. Только `--color-green` и его три состояния.
2. Тени вместо линий. Глубина — волосяная линия, поверхность и свет. Тень допустима только у плавающей панели.
3. Скругления 16–24px. Карточки и поля — `2px`, пилюли — `999px`, арка — `999px 999px 2px 2px`.

## 1. Токены

Уже в `globals.css`, менять только через файл.

| Токен | Значение | Где |
| --- | --- | --- |
| `--color-bone` | `#f2eee4` | фон страницы |
| `--color-porcelain` | `#fbf8f1` | поверхность карточек, бумага записи |
| `--color-clay` | `#e7e0d2` | вторичная поверхность, hover |
| `--color-sage` | `#dee3d8` | только градиент фолбэка и плиты |
| `--color-ink` | `#14160f` | текст, тёмные секции |
| `--color-green` | `#1e5b49` | единственный акцент, заливка CTA |
| `--color-muted` | `#67695c` | вторичный текст, 4.7:1 на кости |
| `--color-line` | `rgb(20 22 15 / .14)` | декоративные линии |
| `--color-line-strong` | `rgb(20 22 15 / .30)` | усиленные разделители |
| `--color-control-border` | `rgb(20 22 15 / .45)` | границы полей, 3.4:1 |

Тёмная тема — `[data-theme="ink"]` на секции: фон `ink`, текст `#f4f0e6`, muted `#9b9d8e`,
accent-text `#96c4ae`, линия `rgb(244 240 230 / .15)`.

Семантику использовать в компонентах: `bg-bg`, `bg-surface`, `text-text`, `text-text-muted`,
`border-line`, `bg-accent`, `text-on-accent`, `text-accent-text`.

**Бюджет акцента:** CTA hero + активный шаг записи + номера программ + hover-состояния
≤ 7% площади экрана. Акцентная заливка всегда с текстом `on-accent` (6.7:1).

## 2. Типографика

| Роль | Шрифт | Размер | Где |
| --- | --- | --- | --- |
| Display | Spectral 400 | `--text-display` (`clamp(2.35rem, 6.4vw, 6.4rem)`) | только H1 героя |
| H1 секции | Spectral 400 | `--text-h1` | манифест, крупные заявления |
| H2 | Spectral 400 | `--text-h2` | заголовки секций |
| H3 | Spectral 400 | `--text-h3` | названия услуг, программ, кейсов |
| Lead | Golos 400 | `--text-lead` | лид героя, вступление шага |
| Body | Golos 400 | `--text-body` | абзацы, ≤ 33rem |
| Small | Golos 400 | `0.8125rem` | мета, подписи, ошибки |
| Micro | JetBrains Mono 400 | `0.6875rem`, tracking 0.16em, UPPER | eyebrow, метки, цены-метки |
| Quote | Spectral 300 italic | `--text-quote` | врезки, подпись основателя |
| Price | Golos 400 `tnum` | `--text-price` | цены, итог |

Правила:
- Кириллица проверена в обоих шрифтах; латиница — только для единиц и латинских названий.
- `tabular-nums` обязательно на ценах, времени, длительности, днях, кодах.
- `text-wrap: balance` — заголовки; `pretty` — абзацы; `hyphens: none` на h1–h3.
- Ручные переносы в H1 героя: «Ваши зубы — / на всю жизнь.» Слово «жизнь.» — курсив.
- Никакого uppercase на заголовках, никакого letter-spacing на body.

## 3. Сетка и ритм

- Контейнер `1440`, поля `clamp(20px, 5vw, 72px)`. Сетка 4 → 8 → 12 колонок (`.grid-12`).
- Секции: `padding-block: var(--spacing-section)` (88–176px).
- Заголовок секции → контент: `--spacing-stack`.
- Вертикальные линии — только в программах и таблице услуг.
- Любой full-bleed элемент — с отрицательным margin по gutter, не `100vw`.
- `overflow-x: clip` на `body`; горизонтального скролла нет ни на одной ширине.

## 4. Компоненты

Все в `src/components/ui` и `src/components/site`. Новые — в том же стиле, не менять существующие.

- **Button** (`ui/button.tsx`): primary / outline / quiet / link / danger; lg 56, md 48, sm 40, icon 44.
  Primary: зелёная заливка, текст `on-accent`, hover светлее, active `scale(0.985)`.
- **Eyebrow**: волосяная черта 24px + mono-метка + опциональная точка акцента.
- **SectionHeader**: линия сверху, eyebrow слева, H2 в 9 колонках, note в 3 колонках справа.
- **Field**: только нижняя граница, высота 52, label mono UPPER, ошибка `--color-danger` под полем.
- **Reveal**: появление 700 мс, отключается `prefers-reduced-motion`; герой — CSS `.enter`, без JS.
- **Dialog** (Radix): фон `surface`, радиус 2, заголовок Spectral, закрытие 44×44.
- **Accordion** (Radix): строка с линией сверху, плюс в круге, поворот 45° при открытии.

### 5.1 Манифест

- Слева eyebrow `01 — Свод правил`.
- Заявление: `text-h1`, 2–3 строки, `max-width: 22ch`: «Мы не делаем улыбки с нуля. Мы сохраняем те, что у вас есть.»
- Справа, ниже: врезка Spectral italic «Лучший имплант — тот, который не понадобился.» + подпись mono.
- Под заявлением — 3 принципа в ряд, каждый с номером `01/02/03` (mono, accent-text) и линией сверху.

### 5.2 Приём

- SectionHeader: «Один визит — одна задача».
- 4 шага в ряд на десктопе: номер, название (h3), длительность (mono), текст (small).
- Линия над каждым шагом; на мобиле — вертикальный список с линией слева.
- Внизу — строка: «Первый визит — 90 минут, 4 900 ₽, зачитываем в лечение» + ссылка на запись.

### 5.3 Услуги

- SectionHeader: «Услуги», note: «Цены фиксируем до начала лечения…».
- Двухколоночная раскладка: слева sticky-оглавление категорий (mono, 6 строк, активная — accent-text),
  справа — группы. На <1024 оглавление не sticky, идёт строкой над списком.
- Строка услуги: сетка `[номер 32] [название+summary] [длительность] [цена] [стрелка]`, линия сверху,
  padding 18–22. Hover: линия темнеет, стрелка уезжает на 4px, фон `porcelain`.
- Название — h3, summary — small muted, цена — `tnum`, «от» — перед числом.
- Клик по строке — выбор услуги в записи (событие `svod:book-service` с `serviceId` + скролл к `#booking`).

### 5.4 Программы

- Три колонки, разделённые вертикальными линиями (на мобиле — горизонтальными).
- Номер `01` в Spectral 200, `accent-text`; название h3; kicker mono; описание small; состав — 4 строки.
- Внизу: цена крупно, старая цена зачёркнута muted; кнопка-ссылка «Выбрать программу →».
- Средняя программа (или первая) может иметь фон `clay` и усиленную линию, но без «популярно» и бейджей.

### 5.5 Врачи

- Горизонтальная лента с snap-scroll, карточки ~300px, фото 4:5, без арки.
- Под фото: имя (18px Golos 500), роль (small muted), стаж (mono).
- Hover: фото `scale(1.03)`, цитата врача выезжает снизу (на тач — видна всегда).
- Стрелки 44×44 справа от заголовка; прогресс-линия под лентой.
- Клик по карточке — выбор врача в записи.

### 5.6 Клиника (тёмная)

- Фон ink, blueprint-сетка по фону с маской.
- Слева фото интерьера (4:5, арка сверху — единственное место, где арка у фото кроме героя) + подпись.
- Справа заголовок «Тишина и увеличение», note, затем 4 строки оборудования: имя (h3), spec (mono, accent-text), текст small.
- Под блоком — `ToothArch` (SVG с 32 зубами, FDI) в две колонки на десктопе, с подписью
  «Схема FDI · 32 зуба · верхняя дуга 11–28, нижняя 31–48». Схема декоративная, `role="img"`.
- На мобиле: фото, список, схема. Схема не меньше 300px по ширине.

### 5.7 Случаи

- Три карточки: схема (SVG 1:1, 120px) слева сверху, заголовок, «Ситуация» / «Решение» (small),
  мета-строка: визиты · срок · цена. Линия сверху, без заливки.
- Схемы — абстрактный разрез зуба: `veneer` (слой на передней поверхности), `endo` (канал с линией),
  `implant` (винт в корне). Только линии и один accent-элемент.
- Подпись секции: «Фотографии не публикуем: только диагноз, решение и цена».

### 5.8 Отзывы

- Маркиза: 56s, пауза на hover/focus + кнопка «Пауза» 44×44, `prefers-reduced-motion` — статичный скролл.
- Карточка: текст small, имя 500, мета mono «услуга · район».
- Между карточками вертикальная линия высотой 100px. Маска краёв 80px.

### 5.9 FAQ

- Две колонки: слева заголовок и note (sticky), справа аккордеон из 6 пунктов.
- Первый пункт закрыт; одновременно открыт один.
- Внизу строка: «Не нашли ответ? Позвоните — +7…» со ссылкой.

### 5.10 Запись

- Фон porcelain, сверху линия. Слева форма (до 40rem), справа summary 380–416px sticky.
- Stepper: `01 Услуга · 02 Врач · 03 Время · 04 Контакты`, активный — accent-text, прогресс 2px.
- Шаг 1: услуги по категориям, radio-строки; шаг 2: врачи для выбранной услуги; шаг 3: 14 дней + слоты
  (утро/день/вечер), empty и error состояния; шаг 4: имя, телефон, email, комментарий, согласие.
- Summary: услуга, врач, дата, время, итог, «Оплата после приёма. Отмена за 6 часов».
- Успех: код `SVD-XXXX` крупно, детали, «Записать ещё», фокус на заголовке.
- Ошибка 409: «Это время только что заняли» + сброс времени и возврат на шаг 3.

### 5.11 Footer

- ink. Слева логотип и одна строка позиционирования. Колонки: часы, адрес, контакты, навигация.
- Внизу: `© 2026 СВОД`, ссылка на `/privacy`, «Не является публичной офертой».
- Мобильный: 2 колонки, контакты доступны без скролла вправо.

## 8. Доступность

- Фокус: `outline: 2px solid var(--color-focus); offset: 3px`, никогда `outline: none`.
- Тач-таргеты ≥ 44px; чекбоксы и радио — нативные или Radix.
- Формы: `<label>`, `aria-invalid`, ошибки в `aria-live="polite"`.
- Радио-группы: `<fieldset><legend class="sr-only">`.
- Диалоги: focus trap, Esc, возврат фокуса.
- Схемы и декоративные SVG: `aria-hidden` или осмысленный `role="img"` + подпись.
- Один `<h1>` на страницу; иерархия без пропусков.
