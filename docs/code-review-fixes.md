## Осознанно оставлено

- **Гонка «удаление услуги ↔ новая бронь» (medium).** Проверка будущих броней и удаление живут в разных документах. При одном администраторе и файловом драйвере окно микроскопическое; для прода с несколькими менеджерами нужен общий advisory-lock на `catalog` + `bookings`. Записано в известные ограничения.
- **Лимит тела только по `content-length` (low).** Сервер читает JSON через `request.json()`; для формы без файлов достаточно. На проде перед Next стоит платформенный лимит.
- **Нет тестов на route handlers (low).** Ядро (слоты, пересечения, коды, пароли, сессии, хранилище, бронь) покрыто 89 тестами; API проверяется смоук-скриптом `scripts/smoke.mjs` на живом сервере.
- **Слой сотрудников без UI (low).** `admin-store` умеет owner/manager и гарды, но экранов управления командой нет — вне объёма демо. Роль `manager` пока не ограничивает разделы: единственный сотрудник — owner.
- **Три телефонных хелпера (low).** Один — маска ввода, второй — нормализация на сервере, третий — формат отображения. Дублирование осознанное: разные зоны ответственности.
- **`content-length`/`now` в `UpdateBookingInput`** — задел на ручные брони; не влияет на поведение.
